# December 2025 Feature Set

## Introduction

These new features shall be added to the obliq-2 application.

| Name           | Class | Description        |
|-----------------|---|-----------------------|
| Model Parameter Support | Model Structure| Models me be assigned one or more name/signal-type/value tuples. Names are any valid block name. Values may be a Scalar, Vector, or Matrix |
| Model Parameter View/Edit | UI | Add a Dialog in the Model editor to interactively Add, Edit, or Delete Model Parameters |
| Integrate Model Parameters inside Simulations | Modeling and UI | ✅ COMPLETE (Dec 2, 2025) - Enhance the Source Block to support referencing of a Model Parameter, either as part of source value. Enhance the Evaluate Block to support parameter references in expressions. Enhance Code Generation to include Model Parameters as constants included in the Model and inserted, where applicable in generated code. |
| Grouped Block Selection | UI | Add the ability to select multiple blocks on a Sheet by mouse-dragging a rectangular region on the Sheet. A Mouse-down in any area of the sheet not associated with a Block or connection will start the selection operation. A Mouse release completes the selection region definition. All blocks inside the region would be selected. Allow adjustment of the selection by Shift-Clicking on a block to add or remove it from the selected block set. Connections between selected blocks and their relative positions are preserved in the selection data. |
| Block Cut/Copy and Paste          |  UI     | Cut or Copy the current selection. Allow the elements in the Copy/Cut Buffer to be pasted onto the same or other Sheets in a Model, or to be pasted into another Model that is open on a different browser tab/window.         |
| Models Page - Duplicate a Model | UI  | Add a "Duplicate..." function to the Model tile. |
| Model Editor - Rename a Block | UI | Add a Block Context Menu function to rename a Block |
| "Limit" Block | Block | Add a Block which limits the value of each output to a specified numeric range. This Block shall accept a Scalar, Vector, or Matrix input Signal. It outputs a signal of the same type. |
| "Integrator" Block | Block | Add a new Block to integrate an input signal. Integration algorithm (RK4 or Euler) is selected at the Model level. The Integrator configuration properies shall specify an initial value (by default, a scalar, vector, or Matrix of zeroes, dependent on the "shape" of the input Signal).  The Integrator block can be configured to expose "Enabled" and/or "Reset" input signals. "Enable" is handled in the same manner as with Subsystem enabling. A rising edge "Reset" signal sets the current value of the outputs to be the configured Initial value(s). The Integrator may optionally include upper and lower limits - when configured, integrated values are clamped element-wise to the specified range. Integration is optimized to skip computation when the integrator is at a saturation limit and the derivative would push it further beyond that limit. |
